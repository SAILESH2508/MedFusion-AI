### FEAT-004 — Backend Consolidated `GET /api/health-twin/` Endpoint

- [ ] 13. **Add `health_twin_view` to `views.py`**
       At the bottom of `backend/medical/views.py`, add a new view:
       ```python
       @api_view(['GET'])
       @permission_classes([IsAuthenticated])
       def health_twin_view(request):
           """
           Consolidated endpoint for the Personal Health Twin page.
           Returns the authenticated patient's profile, predictions,
           pathology reports, and prescriptions in a single call.
           Only serves Patient role users.
           """
           user = request.user
           try:
               patient = Patient.objects.get(user=user)
           except Patient.DoesNotExist:
               return JsonResponse({"error": "Patient profile not found."}, status=404)

           profile_data = {
               "id": patient.id,
               "name": f"{patient.first_name} {patient.last_name}".strip() or user.full_name or "User",
               "first_name": patient.first_name,
               "last_name": patient.last_name,
               "blood_group": patient.blood_group,
               "allergies": json.loads(patient.allergies or '[]'),
               "dob": patient.dob.isoformat() if patient.dob else "",
               "gender": patient.gender,
               "weight": patient.weight_kg,
               "height": patient.height_cm,
               "emergency_contact": patient.emergency_contact,
           }
           predictions = [p.to_dict() for p in patient.predictions.order_by('-created_at')[:20]]
           pathology = [r.to_dict() for r in patient.pathology_reports.order_by('-created_at')[:20]]
           prescriptions = [p.to_dict() for p in patient.prescriptions.order_by('-created_at')[:10]]

           return JsonResponse({
               "profile": profile_data,
               "predictions": predictions,
               "pathology_reports": pathology,
               "prescriptions": prescriptions,
           }, status=200)
       ```
       Files: `backend/medical/views.py`
       Verify: `python manage.py check` — 0 errors.

## Critical Constraints

1. **No DB migrations** — do not touch models.py.
2. **No duplicate engines** — MedicationSafetyPanel calls the existing `/api/telemetry/drug-safety/` endpoint; no new interaction logic.
3. **No fabricated data** — OrganInfoPanel, HealthTimeline, and HealthChangeExplorer only display data that exists in the API response. Empty states are shown otherwise.
4. **Hypothetical values never saved** — HealthChangeExplorer is pure UI state, no POST calls.
5. **3D models are procedural geometry** — no GLTF files; clearly labelled "illustrative, not medically accurate".
6. **Lazy-load the 3D canvas** — `React.lazy()` in DigitalTwin.jsx so the page is usable before Three.js initialises.
7. **Patient-only route** — `/digital-twin` must redirect non-patients (guests, doctors) to `/auth`.
8. **`--legacy-peer-deps`** — required for npm install due to React 19 peer dep conflicts.
